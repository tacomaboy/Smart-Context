Local context held versus context actually sent to the Claude API.

Token counts for sent context are exact, taken from each response's usage object. The prompt-token chart shows input-side prompt tokens only: cache read, cache write, and fresh input. Prompt-cost calculations use Anthropic input list price for the logged request's model family (haiku $1/M, sonnet $3/M, opus $5/M, fable $10/M input tokens). Cost with smart-context uses observed usage-token composition (fresh 1x, cache-read 0.1x, cache-write 1.25x). The without-smart-context comparison and local-held totals are modeled from local chunk sizing, so they remain directional. Output-token billing is excluded. Refreshes every 5s.
